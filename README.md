# AI-Based Classification of Lymph Node FNAC

Research artifact repository for work on AI-based classification of lymph-node fine-needle aspiration cytology (FNAC).

## Paper

- [Research paper PDF](AI_based_classification_of_lymph_node_fnac.pdf)
- [IEEE publication page](https://ieeexplore.ieee.org/document/9984542)

## Research scope

The work explores neural-network approaches to classifying lymph-node FNAC images. The project description identifies CNN, InceptionNet, and ResNet-50 approaches. Refer to the paper for the exact experimental setup, dataset, author contributions, evaluation metrics, and conclusions.

## Repository contents

This repository provides the paper PDF. Training/inference code, data, model weights, and an executable environment are not included. It is a publication artifact rather than a runnable application.
